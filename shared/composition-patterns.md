# Composition Patterns

| Pattern | Layout | Use for |
|---|---|---|
| Hero + ecosystem | Copy on one side; connected central product metaphor | SaaS, integrations, platforms |
| Editorial split | Bold copy column plus one isolated hero | Single premium service/outcome |
| Modular offer | 3–4 cards/modules around an anchor visual | Capability or service menus |
| Proof + process | Claim then a short 3-step path or metric | Consulting and trust building |

Use one hero visual. Keep the reading path: brand → headline → value → visual → CTA → footer. Reserve copy-safe space and keep the footer secondary.

Formats: 1080×1350 (4:5) feed portrait; 1080×1080 square; 1080×1920 story; 1200×627 LinkedIn landscape.
