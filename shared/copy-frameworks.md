# Copy Frameworks

## Message formula

For **[audience]**, get **[outcome]** with **[service]**, so you can **[benefit]**.

## Banner hierarchy

1. Headline: 3–7 words.
2. Supporting line: one concise sentence.
3. Benefits/proof: 2–4 short phrases, all verifiable.
4. CTA: action verb + low-friction next step.
5. Footer: web/contact only if essential.

Prefer specific outcomes over generic words such as “innovative” or “quality.” Do not invent results, client names, prices, or credentials.
