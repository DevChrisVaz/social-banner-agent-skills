# AI Art Direction

Direct a single hero visual that supports the message and leaves room for live copy. Read `../../shared/art-direction-guide.md`.

1. Choose one concrete metaphor for the service.
2. Define composition, hero/supporting elements, palette roles, texture, lighting, view, and explicit text-safe area.
3. Exclude final text, logos, URLs, trademarks, and generic visual clutter.
4. Deliver an art-direction brief; hand prompt construction to `campaign-prompt-builder`.
