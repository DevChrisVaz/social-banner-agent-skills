# Campaign Prompt Builder

Build prompts from approved inputs; do not decide brand strategy or copy here. Read `../../shared/prompt-library.md`.

1. Combine the brand system, composition spec, and art direction into a platform-neutral base prompt.
2. State aspect ratio, text-safe zone, hero location, palette roles, and exclusions.
3. Create 2–4 meaningfully different variants by changing metaphor or composition.
4. Include a negative prompt and a post-generation instruction to add verified text and logos in an editable layout tool.
