# Banner Copy Structure

Write for glanceability and truthfulness. Read `../../shared/copy-frameworks.md`.

1. Turn the offer into one specific outcome for one audience.
2. Draft a 3–7 word headline, one supporting line, 2–4 benefit/proof phrases, and one CTA.
3. Produce alternatives only when they differ strategically (outcome, pain, or proof), not cosmetically.
4. Keep final copy outside generated imagery; it will be placed as live type in the layout stage.
