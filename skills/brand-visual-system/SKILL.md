# Brand Visual System

Create a compact brand brief that downstream banner skills can reuse. Read `../../shared/brand-system-template.md`.

1. Gather verified brand facts: audience, positioning, voice, palette, typography, logo rules, image preferences, prohibited elements, and proof boundaries.
2. Fill the template. Label unknowns as assumptions and never invent assets or claims.
3. State 3–5 non-negotiables and a visual “north star” sentence.
4. Return the brief as a reusable source of truth for `brand-consistency-check`.
