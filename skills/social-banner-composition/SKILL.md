# Social Banner Composition

Choose the layout that makes the message faster to understand, not merely more decorative. Read `../../shared/composition-patterns.md`.

1. Confirm channel, aspect ratio, audience, message, and CTA.
2. Choose one pattern and define the reading path, copy zone, hero zone, supporting elements, and footer.
3. Reserve 35–50% text-safe area when the art leads the composition.
4. Return a compact layout spec suitable for copy and art-direction skills.
